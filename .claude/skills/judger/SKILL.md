# The Judger's assistant (retired)

Retired on 2026-10-17 (R79-8, R79-12). There is no Judger close any more: a
Discord scene, like any other, is archived with `session_end` (or
`archive_scene`) and its Ledger, Fronts, roster and lasting card changes are
kept current quietly, never printed and never proposed line by line
(`wotr-write` §1, `wotr-ledger`). An adjudication card is drafted only when
two players' characters contest a thing or a player asks for one. The old
`judger-assist` workflow and `build/judger_apply.py` are no longer part of the
table; if Isaac types `/judger`, say in one line that it is retired and run
the silent upkeep instead.

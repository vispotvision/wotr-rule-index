# Conflicts — needs Isaac

Anything the extraction could not settle from the source text alone. Append, do
not rewrite. One row per conflict. Keep them small enough to rule on in a
sentence.

Format:

```
## C-001 — short name
**Rules:** R13-4-FOO vs R15-1-BAR
**The clash:** one or two sentences, plain.
**Quotes:** the two lines, verbatim, so the ruling can be made without reopening
the packs.
**Consequence if unresolved:** what a writer cannot do until this is settled.
**Recommendation:** only if a pack itself offers one. Otherwise none.
**Status:** open
```

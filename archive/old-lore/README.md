# Old lore: not canon

Kept for the record, never deleted, never read by the live tools.

- `imports/` the Notion/Trello-era imports (cards, characters, techniques, artifacts) from before the vault.
- `god-hand/` the God Hand account, retconned 2026-10-30: it is not part of the new world.
- The pre-reset scenes and Table live in `lore/v1/` (read only through `scene_recall(old_lore=True)`).

Nothing here is edited, and nothing in `wiki/` or `scenes/` may link to it.

`scripts/` holds the one-time import and publish scripts (lore_publish, lore_roster, publish_imports,
trello_import, trello_images, the character-lore workflow). They read the old `imports/` folders, which now
live in `archive/old-lore/imports/`, and are retired: they will not run from here unchanged.

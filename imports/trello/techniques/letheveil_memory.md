# **LETHEVEIL MEMORY-QUAKE**

_(Amnesia Shockwave)_

## **I. Source & Concept**

Source (Wellsprings):

- **Letheveil** — memory-blur siphoning
- **Hypnather** — half-sleep distortion

Path: Spirit Path
Aether Class: Dreambreaker Aether

Core Concept (Fantasy):
Aeldoris unleashes a pulse that shakes loose recent memories, temporarily disrupting continuity of thought.

## **II. Function + Philosophy**

Function: Mental Debuff / Spellbreak / Cognitive Fracture
Outcomes:

- Removes short-term memory (3–10 seconds)
- Breaks spell-chains that depend on layered recall
- Disrupts combat rhythm
- Weakens Domain concentration

Philosophy:
“Forget the moment — and you forget the reason you fight.”

## **III. Mechanics Spec**

Name: Memory-Quake
Type: Psychic Shockwave
Temperance Requirement: Stage VII Refraction
Activation: Reactive
Range / Area: 25-meter radius
Duration per turn: 1 turn
Tags: Memory, Sleep, Nullification

## **IV. Limits, Weaknesses, & Cost**

Limits:

- Cannot erase deeply-rooted memories
- Only affects conscious targets

Weaknesses:

- Verdantia clarity fields counter memory disruption
- Aether automata remain unaffected

Cost:

- **Recall Slip**: Aeldoris loses one minor memory
- **Temporal Fog**: Momentary confusion for 0.2 seconds

## **V. Counters & Interactions**

- Pain stimuli restore memory scaffolding
- Mental anchors disrupt wave spread
- Echoform entities absorb the shock harmlessly

## **VI. Imagery, Sound, & Sensation**

Visual: Ripples pass through the air like rings in still water.
Sound Cue: A heavy “muffled thump,” as though heard underwater.
Sensation: Thoughts sliding away, blurred edges of memory.

## 7. Jargon

- **Allow-list / deny-list.** An allow-list names what is permitted and hides everything else; a deny-list names what is hidden and shows everything else. Allow-lists hide new fields by default.
- **Anchor (voice).** An approved audio take a character's later takes are measured against.
- **best-of-N.** Generate N takes, score each against the anchor, keep the best.
- **BS.1770 / LUFS.** The broadcast standard for measuring loudness and its unit. -19 LUFS is a normal spoken-word level.
- **CHAP / CTOC.** ID3 frames that store chapter markers inside an MP3.
- **claude -p.** Running Claude Code non-interactively from a script with a single prompt, on the subscription.
- **Cosine (similarity).** A 0-to-1 score of how alike two voice fingerprints are.
- **Cron / scheduled task.** A job the operating system runs on a timer (Windows Task Scheduler here).
- **dBFS.** Decibels relative to the loudest sample a digital file can hold; 0 dBFS clips.
- **Design-then-clone.** Have the voice model design a voice from a text brief once, then reuse that recorded take as the reference for every later line.
- **ECAPA.** A speaker-recognition model that turns a clip into a fingerprint vector.
- **Embedding / semantic search.** Turning text into a list of numbers so that passages with similar meaning sit close together, and searching by that closeness rather than by matching words.
- **Ephemeral (Discord).** A reply only the person who ran the command can see.
- **F0.** The fundamental pitch of a voice, in hertz.
- **Frontmatter.** A few `key: value` lines between two `---` lines at the top of a Markdown file.
- **Front / clock.** A table-side threat with a fixed number of ticks; when the clock fills, the consequence fires.
- **GGUF.** The file format llama.cpp loads models from.
- **Hook (Claude Code).** A script Claude Code runs automatically before or after a tool call, at session start, or when it stops.
- **ID3.** The label block inside an MP3 that players read for title, album and artist.
- **Intent (message_content).** A Discord permission a bot must declare and an admin must enable before it can read message text.
- **JSON-schema-constrained decoding.** Forcing a model's output to match a fixed shape so it cannot answer in prose.
- **Lorebook.** A dictionary of names and terms that, when they appear in a draft, pull the relevant page into the writer's context (build/lorebook.py).
- **M4B.** The audiobook file format; one file per book with chapters and a remembered position.
- **Manifest hash.** A short code computed from a file's content and stored beside the output; if the code changes, the output is rebuilt.
- **MCP.** Model Context Protocol; the way Claude Desktop, the phone and the bot call the tools in build/mcp_server.py.
- **Media overlay / SMIL.** The EPUB 3 mechanism that links each paragraph to a time range in an audio file so a reader can highlight the paragraph being read.
- **Play-by-post.** Roleplay conducted as forum posts over days rather than live.
- **RAG.** Retrieval-augmented generation: fetching relevant passages before the model writes. The wiki and scene_recall tools are this.
- **Read-back.** Transcribing a rendered line with Whisper and comparing it to the script to catch a bad take.
- **ROCm / Vulkan / CUDA.** Three ways software talks to a graphics card. CUDA is Nvidia-only; this PC has an AMD card, so ROCm (AMD's) and Vulkan (vendor-neutral) are what work.
- **RVC.** Retrieval-based Voice Conversion: a model trained on one voice that re-voices any audio into it.
- **Sidecar.** A small file written beside a main file (an MP3's .vtt captions, a scene's assertions).
- **Speaker embedding / fingerprint.** A vector describing a voice's timbre; two clips of one speaker land close together.
- **Stage / Grade / Band.** The Living System's power tiers on a character card.
- **Stop hook.** A Claude Code hook that runs when the session ends a turn.
- **Tupperbox / proxy / webhook.** A Discord bot that reposts a player's message under a character's name through a webhook, hiding the human sender.
- **Venv.** A self-contained Python environment with its own packages; each TTS engine has one under C:\venvs.
- **VoiceDesign.** Qwen3-TTS's mode that invents a voice from a text description rather than cloning a clip.
- **WebVTT.** The web caption format; `<v Name>` tags a cue with its speaker.
- **Whisper.** OpenAI's speech-to-text model; faster-whisper is the fast CPU build used here.
- **Wikilink.** `[[Page Name]]` syntax that turns a name into a link to its page.
- **Worktree (git).** A second checkout of the same repository in another folder; dead ones under .git/worktrees were the stderr chatter that killed the sync.

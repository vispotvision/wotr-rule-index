# The Table — Running Pieces

*The pieces that make the table remember. Consulted at every session start, rewritten at every session end. Built 6 September 2026. Parked under the Scene Archive because the wiki root refused a page_id parent from this integration; move to the wiki root when convenient.*
**How to use this section.** State of Play records where each live thread stands in five to fifteen lines. Fronts are the off-screen agendas that move whether or not the PC is looking. The Ledger is what everything has cost. Open Rulings is what only Isaac can decide. Nothing here is prose; it is bookkeeping, and bookkeeping is what lets the prose remember.
**Protocol.** Session start: read State of Play for the live thread, read the Ledger and pick what comes due, advance one Front, then run the beat or offer the Scene Menu. Session end: rewrite State of Play, append to the Ledger, advance the Fronts, add any new ruling to the docket.
